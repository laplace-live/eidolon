# LAPLACE Eidolon

Milky Green in the dims

Voice companion and local assistant with streamer role-play personas.

Run locally with `npx @laplace.live/eidolon` (Node.js 24+), or use the desktop app. See [laplace.live/eidolon](https://laplace.live/eidolon) for user guides, and [docs/](docs/) for contributor reference.

## System requirements

<!-- Electron 45 floors — pnpm doc-check fails once apps/desktop moves to another major (docs/desktop.md#bumping-electron) -->

- **Desktop app:** macOS 13 Ventura or later (Apple silicon) · Windows 10 or later (x64)
- **CLI / local web app (`@laplace.live/eidolon`):** Node.js 24+ on macOS (Apple silicon), Linux x64/arm64 (glibc), or Windows x64 ([VC++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe))
